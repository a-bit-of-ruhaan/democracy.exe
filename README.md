# Democracy Simulator™

"Because apparently democracy needed a UI update."

A fully functional, purely satirical, and entirely fictional voting simulator web app. 
Designed as a harmless parody/meme game to show off some sleek UI skills while having a bit of fun.

**⚠️ DISCLAIMER: THIS IS A FICTIONAL PARODY — NOT A REAL VOTING SYSTEM**
This project does not connect to any databases, collect real voter information, or represent any real-world political parties, people, or entities. It is a joke.

## Features
- **Sleek, Modern UI**: Dark SaaS aesthetic with glassmorphism and subtle neon gradients.
- **Indian Flag Theme**: Tasteful use of Saffron, White, Green, and Navy Blue.
- **Comedy Mechanics**: The buttons refuse to let you vote for non-favored parties.
- **Absurd Escalations**: Voting for the "right" party triggers a hilariously long, fake processing sequence.
- **Media Ready**: Easy placeholders to drop in your own funny sounds or memes.
- **Responsive**: Looks great on desktop, laptop, and mobile devices.

## How to Run
It's just HTML, CSS, and vanilla JS! No build steps required.
1. Clone or download this repository.
2. Open `index.html` in your favorite web browser.
3. Enjoy the illusion of choice!

## Customizing Media Placeholders
If you want to add a meme image or a sound effect:
1. Place your image in the `assets/images/` folder.
2. Place your sound in the `assets/sounds/` folder.
3. Open `script.js` and update the first two lines:
   ```js
   const memeImage = "assets/images/your-meme.jpg"; 
   const voteSound = "assets/sounds/your-sound.mp3"; 
   ```
